# Microtaller 29 – Análisis de riesgos de un proyecto tecnológico

Módulo 3. Inteligencia de negocios y toma de decisiones · Santiago Gutierrez Moralez

Dashboard interactivo de riesgos de un proyecto ficticio (plataforma web y app móvil de inventarios).

- **Dashboard desplegado:** https://vantasec1727.github.io/riesgos-microtaller29/
- `index.html` – dashboard (HTML + CSS + JavaScript, sin dependencias)
- `riesgos_proyecto.csv` – base de datos de 25 riesgos ficticios
- `captura_dashboard.png` – captura del dashboard
- `Microtaller29_Riesgos_SantiagoGutierrez.docx` / `.pdf` – informe de entrega
- `.github/workflows/pages.yml` – despliegue automático con GitHub Actions

Puntaje = probabilidad × impacto → Alto (15–25), Medio (7–14), Bajo (1–6).
Datos ficticios con fines académicos.
